DSC8307 – Data Mining, Modeling and Analytics
1. Project Overview
This repository contains the practical implementation of the DSC8307 Data Mining, Modeling and Analytics course project.
The project applies supervised machine learning techniques to two datasets to develop predictive models, evaluate their performance and generate insights from data.
The project consists of two parts:
Part A: Bank Marketing Classification
This part focuses on predicting whether a bank customer will subscribe to a term deposit based on customer characteristics and previous marketing campaign information.
Classification algorithms are developed and evaluated using appropriate performance metrics to identify suitable approaches for predicting customer subscription.
Part B: Concrete Compressive Strength Prediction
This part focuses on predicting the compressive strength of concrete using its composition and curing age.
Regression models are developed and compared to identify the most accurate approach for predicting concrete strength.
2. Project Objectives
The main objectives are to:
•	Explore and understand the datasets.
•	Perform data cleaning and preprocessing.
•	Conduct exploratory data analysis and visualisation.
•	Develop appropriate classification and regression models.
•	Compare model performance using suitable evaluation metrics.
•	Examine prediction errors and model limitations.
•	Identify important predictors and interpret the findings.
•	Recommend suitable predictive models based on empirical evidence.
3. Technologies and Tools
The project uses the following technologies:
•	Python – programming and data analysis.
•	Jupyter Notebook – interactive development and documentation.
•	Pandas and NumPy – data manipulation and numerical computations.
•	Matplotlib and Seaborn – data visualisation.
•	Scikit-learn – data preprocessing, machine learning and model evaluation.
4. Repository Structure
•	data/ – datasets used in the analysis.
•	notebooks/ – Jupyter Notebooks containing the analysis and model development.
•	requirements.txt – Python dependencies.
•	.gitignore – files and folders excluded from version control.
5. Installation and Setup
To reproduce the analysis:
1.	Clone or download this repository.
2.	Install the required Python packages:
pip install -r requirements.txt
3.	Launch Jupyter Notebook:
jupyter notebook
4.	Open the relevant notebook in the notebooks/ directory.
5.	Ensure the datasets are available in the expected data/ directory.
6.	Run the notebook cells sequentially.
6. Reproducibility
The notebooks document the data preparation, exploratory analysis, model development, evaluation and interpretation processes.
The project uses Python and Scikit-learn to support reproducibility of the machine learning workflows.
